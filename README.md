# Raspberry Pi Security Lab

This repository documents my Raspberry Pi 5 cybersecurity home lab. The goal of this lab is to build hands-on experience with Linux administration, SSH security, firewall configuration, log monitoring, and defensive cybersecurity tools.

## Lab Device

- Raspberry Pi 5
- Ubuntu Server LTS
- SSH enabled on a non-default port
- UFW firewall enabled
- Fail2Ban configured for SSH protection
- Tailscale used for private remote access

## Projects

1. UFW Firewall Setup
2. SSH Hardening
3. Fail2Ban Intrusion Prevention
4. Tailscale Remote Access
5. Docker Security Lab
6. OWASP Juice Shop Practice

## Purpose

This lab helps me practice real-world IT and cybersecurity skills in a safe and legal environment.
